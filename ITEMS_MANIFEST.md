# ITEMS_MANIFEST: Steal a Fish

Every item for **Steal a Fish** (Filipino fishing theme): 59 low-poly OBJ meshes, 2 shared texture atlases,
65 icons at 512x512, and 13 Luau modules. All of it is generated by the Python scripts in `tools/items/`
(numpy + Pillow, no Blender).

## Status

| Phase | Status |
|---|---|
| 1. Folders, manifest, item data | done: 65 items in 9 categories, economy simulated |
| 2. Fish meshes + textures | done: 24 fish, 392-776 tris each, `fish_atlas.png` |
| 3. Nets, tanks, locks, boosts, cosmetics meshes | done: 35 meshes, 168-2,148 tris each, `props_atlas.png` |
| 4. Icons | done: 65 icons, 512x512 RGBA |

| 6. Studio import steps | done (below) |

## Folder layout

```
items/models/      <item_id>.obj: one per item, studs, Y-up, front = -Z, pivot at base (min Y = 0, centered X/Z)
items/models/_model_report.json   triangle count + bounds per mesh (generated)
items/icons/       <item_id>.png: 512x512 RGBA, transparent corners, rarity frame + 1-5 stars
items/textures/    fish_atlas.png (1024, 24 fish cells) + props_atlas.png (1024, swatches + pattern tiles), opaque RGB
items/item_data.json      every item's data as JSON (generated)
items/balance_table.json  economy simulation output (generated)
studio/items/      Luau ModuleScripts + StudioSetup command-bar script
tools/items/       generators: item_data.py (single source of truth), balance_sim.py, meshlib.py,
                   gen_fish.py, gen_props.py, gen_icons.py, gen_luau.py, manifest_tables.py
```

To rebuild everything (about 1 minute), run from `tools/items/` after `pip install -r requirements.txt`:

```
python item_data.py && python balance_sim.py && python gen_fish.py && python gen_props.py \
  && python gen_icons.py && python gen_luau.py && python manifest_tables.py
```

To test the Luau, install the [Luau CLI](https://github.com/luau-lang/luau/releases), then run
`python gen_luau.py --bundle && luau /tmp/luau/bundle.luau`. It should print `ALL 48 CHECKS PASSED`.

## Roblox Studio import steps

**1. Create the folders.** Open your place, then View > **Command Bar**. Paste all of `studio/items/StudioSetup.luau`
and press Enter. This creates `ReplicatedStorage.Items.{Modules, Models/<Category>, Materials}` and
`ServerStorage.Items.ServerModules`, with placeholder ModuleScripts. Open each placeholder and paste in the
matching `.luau` file. If you use Rojo, map `studio/items/*.luau` into the same folders instead.

**2. Import the 59 meshes.** Use File > **Import** (the 3D Importer with its import queue). Select every file in
`items/models/*.obj` at once. In the queue, use "apply to all" with these settings:

| Section | Setting | Value | Why |
|---|---|---|---|
| File General | Import Only As Model | On (default) | one MeshPart per file |
| File General | Upload to Roblox | On | creates the mesh assets (ids) |
| File General | Add to Workspace | **On** | the game gets permission, and step 4 reads ids from Workspace |
| File General | Set Pivot to Scene Origin | On (default) | the OBJ origin *is* the base center, so the pivot lands at the base |
| File General | Anchored | On | display props |
| File Transform | World Forward / World Up | Front / Top (defaults) | files are Y-up, front = -Z |
| File Geometry | Scale Unit | **Studs** (default) | OBJ coordinates are already in studs |
| File Geometry | Merge Meshes / Invert Negative Faces | Off / Off | single mesh per file, winding is already correct |
| Object Geometry | Make Double Sided | Off | net bags already have inner walls; double-sided costs performance |

There is no `.mtl` file on purpose: the importer would otherwise upload the atlas 59 times.

**3. Upload the images.** Open Window > **Asset Manager** > **Bulk Import**. Select `items/textures/fish_atlas.png`,
`items/textures/props_atlas.png` and all 65 files in `items/icons/*.png`. When the upload finishes, go to
Asset Manager > Images, right-click each image > **Copy ID**, and paste the numbers into `AssetMap.RealIds`
(`FishAtlas`, `PropsAtlas`, and `icon = ...` per item).

**4. Collect the mesh ids automatically.** Keep the imported meshes in Workspace and run this in the Command Bar:
```lua
require(game.ReplicatedStorage.Items.Modules.AssetMap:Clone()).PrintRealIdsFromWorkspace()
```
It prints a complete `AssetMap.RealIds = { ... }` block with every `mesh = <id>` filled in, and keeps the icon
ids you already pasted. Copy it over the `RealIds` section of the AssetMap ModuleScript. The `:Clone()` makes
Studio re-read the edited module.

**5. Swap the placeholders and build the templates.** Run this one line in the Command Bar:
```lua
require(game.ReplicatedStorage.Items.Modules.AssetMap:Clone()).BuildMeshTemplates()
```
For every item with a real mesh id, it creates `ReplicatedStorage.Items.Models.<Category>.<itemId>` through
`AssetService:CreateMeshPartAsync`, using these settings: TextureID = the matching atlas,
`PivotOffset` at the base, Anchored, SmoothPlastic, CollisionFidelity Box, RenderFidelity Automatic.
CanCollide is on only for tanks, locks and boats, and CastShadow is off for fish. Afterwards, delete the
imported copies from Workspace. At runtime, `AssetMap.SwapPlaceholders` runs automatically on `require`, so
`AssetMap.GetIcon(id)` returns real ids everywhere.

**6. SurfaceAppearance (optional).** The atlases are flat colors, so plain `TextureID` is the cheapest choice
for phones and the default. If you want SurfaceAppearance anyway: insert one into
`ReplicatedStorage.Items.Materials`, name it `FishAtlas`, set **ColorMap** = `rbxassetid://<fish atlas id>`
and **AlphaMode** = Overlay. Repeat for `PropsAtlas`, then re-run step 5. The builder clones it into each
MeshPart instead of setting TextureID.

**7. Per-category notes.**
- **Fish**: every model is 2 studs long. Spawn with `template:Clone()`, then `part.Size = part.Size * fish.sizeScale`.
  Legendary/Mythic (`RarityConfig.glow`): add a PointLight or ParticleEmitter if you like.
- **Hats**: create an `Accessory`, put the template inside renamed `Handle`, and add an Attachment named
  `HatAttachment` at `(0, -Handle.Size.Y/2, 0)`. Then call `Humanoid:AddAccessory` on the server.
- **Bangka skins**: visual hull only. Weld one to your boat chassis or VehicleSeat. All 6 share one shape.
- **Laser fence**: the beams are red in the atlas. For a glow, add thin Neon parts over them.
- **Gamepasses / dev products**: create them on Creator Dashboard > Monetization (upload `items/icons/gp_*.png` /
  `dp_*.png`), then paste the ids into `ShopData` (`gamePassId` / `productId`, placeholder `0`).
  `ShopData.ListPlaceholders()` lists any you missed.

**Troubleshooting**
- Textures look scrambled or upside down on the meshes: regenerate with `ITEMS_FLIP_V=1 python gen_fish.py && ITEMS_FLIP_V=1 python gen_props.py`, then re-import.
- A model faces backwards: set World Forward to Back in step 2. All files use front = -Z, so the same fix applies to every file.

## Decisions log

1. **MAP_MANIFEST.md does not exist.** `nate1231231/steal-a-fish` was created empty (no commits, no branches) one minute before this run, so I followed the prompt instead: **1 stud = 0.28 m**, the folder layout above, and a bright low-poly cartoon style (flat-shaded props, smooth fish bodies, saturated palette, dark outline on icons). If a MAP_MANIFEST.md appears later, change the constants in `item_data.py` / `meshlib.py` and rebuild. Studio's Importer has used 25:7 studs/m (= 0.28 m) since June 2026, which agrees with this scale.
2. **Python deps**: numpy and Pillow were missing. One `uv pip install numpy pillow` into `/tmp/itemsvenv` (outside the repo) worked on the first try. I also downloaded the Luau CLI once, only to test the modules.
3. **Units**: OBJ coordinates are in studs, so import with Scale Unit = Studs.
4. **Gameplay scale**: a 1.7 m avatar is about 6 studs, so true-to-life fish would be tiny (dilis 0.4 studs). Fish OBJs are baked at a **2-stud base length** and scaled per species with `sizeScale` (0.55 to 3.0). Tanks, locks and boats are about 1.5 to 2x real size: the bucket is 2.7 studs, the Ocean Dome 13.8, the bangka 16.3 long.
5. **Mesh reuse vs one OBJ per item**: there are 5 fish body variants (`slender`, `deep`, `tuna`, `squid`, `crab`) from one generator with per-species proportions. Each species still gets its own OBJ only because its UVs point at its own cell in the single `fish_atlas.png`. Roblox can't offset UVs per instance, so 24 small meshes (under 800 tris) plus **one** texture beats 5 meshes plus 24 textures on phones. Props work the same way: shared builders (hand net, rod, bottle, lathe, bangka hull, tank frame) and one `props_atlas.png` palette. All 6 bangka skins and all 4 hand-net tiers are identical geometry with different swatch UVs.
6. **No unneeded transparency**: tanks are open-front dioramas with an opaque back wall, and buckets, tubs and ponds show an opaque water surface, so no glass alpha is needed. Net bags use an opaque woven-grid tile with inner walls. Only the icons have alpha.
7. **Winding is verified**: every primitive orients its triangles outward explicitly. A signed-volume check runs per part, and the icon rasterizer culls back faces exactly like Roblox, so a flipped face would show up as a hole. The `invertedParts` entries in `_model_report.json` are intentional: inward-facing net-bag walls and open bobber half-shells.
8. **Icons are rendered from the exported OBJ files and atlases**, so they show exactly what ships. Shop icons use in-memory coin, crown, sack and chest meshes plus "2x", "AUTO" and "VIP" labels. Non-fish items got a `rarity` purely to color their icon frames.
9. **Economy** (`balance_sim.py`: 40 simulated players, casting 60% of the time, no boosts, gamepasses or steals):
   - Roll weights are 75 / 20 / 2.5 / 0.3 / 0.012. Luck multiplies a rarity's weight by `(1+luck)^exp`, with exp = 0 / 0.5 / 1 / 1.5 / 2.
   - Prices: net = `800 x 9.5^(tier-2)`, tank = `2,500 x 13^(tier-2)`, both rounded half-up to 2 significant digits.
   - Rebirth costs `10M x 5^r`. It resets cash and fish, keeps everything else, and gives +50% income and +0.1 luck per rebirth.
   - First pass: all upgrades were done in 2.4 h, too fast, so I retuned. Final: Golden Trawl at about 9.7 h.
   - The first hour is deliberately fast (the hook).
   - **Update (mutations run):** stars and mutations made progression about 13% faster, so net prices are now `1,000 x 9.5^(tier-2)`, tank prices `3,100 x 13^(tier-2)` and rebirth `12M x 5^r`. With stars and mutations on, Golden Trawl lands at about 9.96 h. The auto table below is the **items-only** Python baseline, which is now slower (about 10.7 h). The full-game table lives in `MUTATION_MANIFEST.md` and `EconomyBalance.BalanceTable`.
10. **Boost prices and cash packs scale with income** (`priceSecondsOfIncome`, `cashSecondsOfIncome`), so they stay meaningful for the whole 10 hours.
11. **Item IDs**: lowercase `category_name` with prefixes `fish_`, `net_`, `tank_`, `lock_`, `boost_`, `skin_`, `hat_`, `gp_`, `dp_`. The file names match the ids.
12. **Luau is generated** from `item_data.py` (data modules, EconomyBalance, AssetMap), so prices, ids and the balance table can't drift. ItemRegistry, LootRoller and StudioSetup are hand-written. Plain Luau without strict types, chosen for beginners. Data tables are `table.freeze`d.
