# ITEMS_MANIFEST: Steal a Fish

Every item for **Steal a Fish** (Filipino fishing theme): low-poly OBJ meshes, shared texture atlases,
512x512 icons, and Luau data modules. All of it is generated by the Python scripts in `tools/items/`
(numpy + Pillow, no Blender).

## Folder layout

```
items/models/      one OBJ per item (<item_id>.obj), Y-up, pivot at base (min Y = 0, centered X/Z), front = -Z
items/icons/       one 512x512 RGBA PNG per item (<item_id>.png)
items/textures/    shared atlases (fish_atlas.png, props_atlas.png), max 1024x1024
items/item_data.json   machine-readable copy of all item data (generated)
items/balance_table.json   economy simulation output (generated)
studio/items/      Luau ModuleScripts + Studio setup script
tools/items/       generators (python3 + numpy + pillow, see requirements.txt)
```

Rebuild everything: `pip install -r tools/items/requirements.txt`, then from `tools/items/` run
`python item_data.py && python balance_sim.py && python gen_fish.py && python gen_props.py && python gen_icons.py && python gen_luau.py && python manifest_tables.py`.

## Decisions log

1. **MAP_MANIFEST.md does not exist.** The GitHub repo (`nate1231231/steal-a-fish`) was created empty (no commits, no branches) one minute before this run. I followed the rules from the prompt instead: **1 stud = 0.28 m**, the folder layout above, and a "bright low-poly cartoon" style (flat-shaded hard props, smooth-shaded fish bodies, saturated palette, dark outline on icons). If a MAP_MANIFEST.md shows up later with different rules, change the constants at the top of `tools/items/item_data.py` and `meshlib.py` and rerun.
2. **Python deps**: numpy/Pillow were missing. One `uv pip install numpy pillow` into a venv outside the repo (`/tmp/itemsvenv`) succeeded on the first try, so I didn't retry anything.
3. **Units**: OBJ coordinates are in **studs**. Import with Scale Unit = Stud. Real-world size is `studs x 0.28 m`.
4. **Gameplay scale**: a 1.7 m avatar is about 6 studs, so true-to-life fish would be tiny (a dilis would be 0.4 studs). Every fish OBJ is baked at a **2-stud base length**, and the game multiplies by the per-species `sizeScale` (0.55 to 3.0). Tanks, locks and boats are cartoon-exaggerated, roughly 1.5 to 2x real size.
5. **Mesh reuse vs one-OBJ-per-item**: there are 5 fish body variants (`slender`, `deep`, `tuna`, `squid`, `crab`), all built by the same generator with per-species proportions. Each species gets its own OBJ only because its UVs point at its own cell in the shared `fish_atlas.png`. Roblox can't offset UVs per instance, so on phones, unique tiny meshes plus **one** shared texture is cheaper than shared meshes plus 24 textures. Props and cosmetics work the same way: shared builders (hand-net, rod, bottle, lathe, bangka hull) plus one `props_atlas.png` palette, with recolors done through UVs.
6. **No unneeded transparency**: tanks are open-front dioramas with an opaque back wall and water surface, so they need no glass. Nets use an opaque woven-grid texture instead of alpha holes. Only icons have alpha.
7. **Economy model** (tuned with `balance_sim.py`, 40 simulated players, 60% active-play efficiency, no boosts/gamepasses/steals): rarity roll weights 75 / 20 / 2.5 / 0.3 / 0.012. Luck raises the weight of rarity `r` by `(1+luck)^exponent[r]` (exponents 0 / 0.5 / 1 / 1.5 / 2). Net price = `800 x 9.5^(tier-2)`, tank price = `2,500 x 13^(tier-2)`, rounded to 2 significant digits. Rebirth = `10M x 5^r`: it resets cash and fish, keeps nets/tanks/locks/cosmetics, and gives +50% income and +0.1 luck per rebirth. The first tuning pass finished all upgrades in 2.4 h, so I lowered high-rarity odds and steepened the curves. The final pass reaches Golden Trawl at about 9.7 h. The first hour is deliberately fast (the hook).
8. **Catch chance**: each fish has a `catchWeight` (relative within its rarity) and a derived `catchChance` (% at luck 0).
9. **Boost prices and cash packs scale with income** (`priceSecondsOfIncome`, `cashSecondsOfIncome`), so they stay relevant across the whole 10 h instead of becoming free or useless.
10. **Item IDs** are lowercase `category_name`: `fish_`, `net_`, `tank_`, `lock_`, `boost_`, `skin_`, `hat_`, `gp_`, `dp_`.
